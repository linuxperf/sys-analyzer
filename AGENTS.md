## Agent skills

### Issue tracker

Issues and specs are tracked in GitHub Issues (`linuxperf/sys-analyzer`) via the `gh` CLI. See `docs/agents/issue-tracker.md`.

### Triage labels

Triage uses the default five canonical labels (`needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`, `wontfix`). See `docs/agents/triage-labels.md`.

### Domain docs

This repo uses a single-context domain doc layout (`GLOSSARY.md` + `docs/adr/` at the repo root). See `docs/agents/domain.md`.
